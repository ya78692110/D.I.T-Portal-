# D.I.T Portal 🎓

A modern and responsive web portal designed specifically for D.I.T (Diploma in Information Technology) students and coursework management.

## 🚀 Features
- **Clean & Modern UI:** Styled with a sleek dark theme and smooth visual effects.
- **Responsive Design:** Works seamlessly across mobile phones, tablets, and desktop screens.
- **Easy Navigation:** Organized sections for quick access to subjects, notes, and topics.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3*
- **JavaScript**

## 🌐 Live Demo
You can view the live project here: https://ya78692110.github.io/D.I.T-Portal-/

## 📂 Project Structure
- `index.html` - Main landing page and layout structure
- `style.css` - Custom styles, dark theme, and responsiveness
- `script.js` - Interactive elements and navigation logic
